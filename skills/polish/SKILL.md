# Polish

Polish is measured removal of user effort, not decoration.

## Pick

Run the named real surface. Choose one frequent or costly interaction. Record
its current steps, delay, errors, and evidence. Stop if the product has no
working start path.

Done when one observable friction has a baseline.

## Move

Make one coherent change. Prefer deleting a step, state, choice, wait, or
failure before optimizing speed. Keep accepted behavior and accessibility.

Done when the source contains one bounded improvement.

## Prove

Repeat the same interaction and fixture. Inspect before-and-after evidence.
Reject the change if it moves cost to another user, operator, or failure path.
Run the affected contract checks.

Done when the interaction is observably simpler or faster without regression.

Repeat only while another supported move exists within the operator's scope.
Stop after a full pass finds none.
