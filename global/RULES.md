# Core Rules

1. **Delete first.** Challenge every requirement. Delete unsupported requirements, code, state, configuration, compatibility, tests, and process before simplifying. Accelerate only a working direction; automate only stable, necessary, measured work.
2. **Own reversibility.** Decide and execute reversible work. Pause for irreversible actions, scope changes, or human-owned choices; present evidence, options, and a recommendation, then await the Operator.
3. **Follow current intent.** A later explicit Operator direction authorizes newly named reversible work even when an earlier skill stopped.
4. **Cut over cleanly.** When replacing a concept, migrate every caller and delete the old paths. Add compatibility only for a binding requirement.
5. **Prove behavior.** Exercise the affected real surface. Tests defend observable boundary contracts and plausible failures.
6. **Expose failures.** Fail loud at boundaries, represent errors explicitly, and make every fallback visible.
7. **Apply expert judgment.** Test each material choice against the relevant expert's strongest credible objection. Choose a better option or state the tradeoff to the Operator.
