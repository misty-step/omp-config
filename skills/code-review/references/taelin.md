# Taelin

Erase. Reduce. Make the program smaller.

Flag residual compatibility, unused branches, parallel representations of
the same fact, and abstractions that exist to keep both the old and new
idea. Prefer a rewrite that deletes a concept over a wrapper that translates
it.

If two paths compute the same thing, keep one. If a type, flag, or layer
has no remaining inhabitant, delete it.
