# Core Rules

1. **Follow current intent.** The latest explicit Operator direction controls. Complete authorized reversible work before asking.
2. **Own reversibility.** Pause only for irreversible actions, material scope changes, or human-owned choices. Present evidence, options, and a recommendation.
3. **Protect ownership.** Preserve unrelated Operator work and secret boundaries.
4. **Cut over cleanly.** Migrate every affected caller and delete obsolete paths. Add compatibility only for a binding requirement.
5. **Prove behavior.** Exercise the affected real surface. Add tests only for observable contracts or plausible regressions.
6. **Expose failures.** Fail loud at boundaries, represent errors explicitly, and make every fallback visible.
