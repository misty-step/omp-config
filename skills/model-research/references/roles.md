# Roles

| Role | Main evidence |
|---|---|
| default, task | Coding-agent results and tool use |
| slow, reviewer | Defect detection and long task results |
| plan, advisor | Plan quality and technical judgment |
| designer | Design Arena, code results, and image input |
| vision | Image input and visual task results |
| smol, tiny, commit | Speed after the required quality level |
| security-reviewer | Security results and defect detection |

For a fallback route, keep the required input type and effort. Change the
provider near the start of the route. Use only a model with valid local access.
Use an OpenRouter model at the end of the route.
