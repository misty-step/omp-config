# Brief reader test

Write for a technical reader who has only the request and this brief. Lead with
the conclusion. Explain the minimum context, causes, stakes, constraints,
uncertainty, and consequences needed to trust it.

Use current primary records. Define necessary terms. Replace vague references
with exact names. Remove chronology and mechanics that do not change
understanding.

Test the draft as a new reader: Can they name the subject, current state, why it
matters, the decision, and the next action? Repair every missing dependency.

Done when the brief needs no transcript, repository tour, or verbal supplement.
