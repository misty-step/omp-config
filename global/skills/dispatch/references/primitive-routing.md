# Native dispatch route matrix

Route by the observable outcome.
The chief owns intent, shared contracts, integration, and final judgment.
Each native agent owns one bounded lane and one kit.

## Routes

| Outcome | Native agent | Method or skill | Oracle |
|---|---|---|---|
| system architecture | `architect` | brief `codebase-design`; `mcp-design` or `eval-design` when needed | boundary proposal, dependency graph, and reversal condition |
| accepted implementation | `builder` | kit `deliver` + `ci` | real entrypoint plus required repository gate |
| security or code review | `verifier` | kit `verify` with lens `security`, `tests`, `vision`, or `review` | ranked finding with a reproducible trigger or static evidence |
| structure and simplicity critique | `sculptor` | kit `prune` | ranked deletion or deepen list with net counts |
| live QA | `verifier` | kit `verify` → live branch | live result against the acceptance oracle |
| incident reproduction | `verifier` | kit `verify` → live branch | original failure replay plus live signal |
| broad research | `researcher` | kit `research` | cited source packet and uncertainty statement |
| external API research | `researcher` | kit `research` and official documentation | primary citation and runnable request shape |
| UI or product design | `designer` | kit `design`; brief prototype/improve-ui when needed | rendered inspection and acceptance evidence |
| persona QA | chief → `qa-master` → `qa-persona` | kit `qa-users` + leaf `qa-persona` | real local, dev, or staging browser scenarios |

The five broad agents are `architect`, `builder`, `verifier`, `researcher`, and `designer`.
`qa-master` and `qa-persona` exist only for the required persona depth.
`sculptor` exists only for the required structure lens in a critic gate.

## Method consolidation

Put repository inventory, API research, library research, and source synthesis in a `researcher` brief.
Put code review, security review, live verification, and incident reproduction in a `verifier` brief.
Put deletion and deep-module critique in a `sculptor` brief.
Do not create durable method-specific agents.

Use the chief for cross-lane coordination.
Do not insert a coordinator between the chief and an executive.
Dispatch multiple agents only when their work is independent.

## Native execution

OMP selects the model, tools, and autoloaded skills from each declaration.
The task brief supplies the outcome, scope, oracle, evidence, and non-goals.
The brief can narrow work by instruction.
It cannot add tools to the declaration.

OMP cannot choose a different model or tool envelope for one native spawn.
Do not emulate that feature with a process wrapper or generated declaration.
Change a durable agent ladder only when its normal work changes.

The only child route is `qa-master` → `qa-persona`.
Every other native agent has no child authority.
Keep `task.maxRecursionDepth` at two.
Respect `task.maxConcurrency`.

## MCP and tool routes

Use LSP for symbol intelligence.
Use browser or `agent-browser` for rendered behavior.
Use `exa-mint` and `firecrawl-mint` for research acquisition.
Use `parallel-search` as additional web search when useful.
Follow `mcp-pruning.md` for every other MCP.
Use Mint for credentialed vendor calls.
Never put provider credentials in a task brief.

## Verification

Add one independent verifier for medium-risk work.
Add a verifier and review for high-risk work.
Unknown risk uses the medium-risk floor.
The verifier returns evidence and never repairs findings.
Every substantive critic gate includes one fresh `sculptor` lane.
