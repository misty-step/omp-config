# Image generation

Use image generation when a visual artifact carries information that prose, HTML, Mermaid, or a table cannot provide.
Call provider APIs through the Mint broker.
Do not gate this capability on one harness's native image tool.

## Authentication

Use value-free placeholders in provider credential fields:

- Gemini: `__mint.gemini.default__`
- OpenAI: `__mint.openai.default__`

Use these Mint routes:

- Gemini: `http://mint.tail5f5eb4.ts.net:4949/proxy/https/generativelanguage.googleapis.com/v1beta/<path>`
- OpenAI: `http://mint.tail5f5eb4.ts.net:4949/proxy/https/api.openai.com/v1/<path>`

Tailnet WhoIs identifies callers. Mint policy grants access and owns
`Authorization`. Never print or store resolved credential values.

## Gemini request

Google's current image API uses the Interactions API.
Use `POST http://mint.tail5f5eb4.ts.net:4949/proxy/https/generativelanguage.googleapis.com/v1beta/interactions`.
Send `x-goog-api-key: __mint.gemini.default__` and `Content-Type: application/json`.

```json
{
  "model": "gemini-3.1-flash-image",
  "input": [
    {"type": "text", "text": "<prompt>"},
    {"type": "image", "mime_type": "image/png", "data": "<base64>"}
  ],
  "response_format": {
    "type": "image",
    "mime_type": "image/jpeg",
    "aspect_ratio": "16:9",
    "image_size": "2K"
  }
}
```

Use uppercase `K` in image sizes: `512`, `1K`, `2K`, or `4K`.
Add prior images as `image` items for edits, style matching, or character consistency.
Use up to 14 reference images.
Read generated bytes from `interaction.output_image.data` and decode the base64 value.
Confirm this schema against Google's current [image-generation guide](https://ai.google.dev/gemini-api/docs/image-generation) before changing it.

## OpenAI request
Use `POST http://mint.tail5f5eb4.ts.net:4949/proxy/https/api.openai.com/v1/images/generations` with `Authorization: Bearer __mint.openai.default__`.
Send this JSON shape:

```json
{"model":"<image-model>","prompt":"<prompt>","size":"1536x1024","quality":"high","n":1}
```

Use `POST http://mint.tail5f5eb4.ts.net:4949/proxy/https/api.openai.com/v1/images/edits` with the same authorization header for edits or inpainting with an input image and optional mask.

## Safety and handling

Upload only images for which you have the necessary rights.
Do not generate infringing, deceptive, harassing, or harmful content.
Gemini images carry a SynthID watermark.
Use watermarked images internally, disclose external use, and never present them as non-AI.
Generated diagrams can be subtly wrong.
Use them for overviews or visual style, and keep Mermaid or code for precise call graphs.
Skip decoration when prose, HTML, Mermaid, or a table can provide the same information.
Expect about four seconds per image; use one request for one-off work.
Save outputs under a scratch or work directory.
Never commit raw model output or raw diffs except in allowlisted fixture directories.
Redact and allowlist content before publishing it downstream.
