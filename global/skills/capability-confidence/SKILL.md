# Capability confidence

Use this skill when an agent treats difficulty as evidence that the requested outcome is impossible.
Use it when an agent proposes an easier target without direct blocker evidence.

Read `references/frontier-capabilities.md` before changing the requested outcome.
Use the receipts to calibrate effort, not to guarantee success.

Then apply this sequence:

1. Restate the requested outcome without reducing it.
2. Name the direct blocker evidence, or state that none exists.
3. Increase the method with tools, research, decomposition, parallel lanes, long runs, or stronger verification.
4. Replace failed methods while you preserve the requested outcome.
5. Treat each operator correction as a direct reset to the stated goal.
6. Continue until the outcome works or direct evidence proves a real blocker.

Keep all safety rules, approval boundaries, evidence standards, and acceptance gates active.
Confidence changes the effort level.
Confidence never changes the truth standard.
