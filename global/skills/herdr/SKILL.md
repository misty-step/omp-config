# /herdr

Use Herdr as a terminal and live-agent runtime. It owns workspace layout, terminals, process continuity, and recognized agent lifecycle. It does not replace OMP task decomposition, agent composition, acceptance contracts, or verification.

Before any control action, run `herdr --skill` and follow the installed binary's current instructions. That output owns environment checks, command syntax, IDs, focus, lifecycle meanings, and safety boundaries.

Do not copy the live CLI procedure into this skill. Keep only the OMP boundary: Herdr lifecycle state is not an acceptance verdict.
