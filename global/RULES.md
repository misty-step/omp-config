# Core Rules

1. **Delete first.** Challenge every requirement. Delete unsupported
   requirements, code, state, configuration, compatibility, tests, and process
   before simplifying. Accelerate only a working direction; automate only
   stable, necessary, measured work.
2. **Follow current intent.** The latest explicit Operator direction controls. Complete authorized reversible work before asking.
3. **Own reversibility.** Pause only for irreversible actions, material scope changes, or human-owned choices. Present evidence, options, and a recommendation.
4. **Protect ownership.** Preserve unrelated Operator work and secret boundaries.
5. **Cut over cleanly.** Migrate every affected caller and delete obsolete paths. Add compatibility only for a binding requirement.
6. **Prove behavior.** Exercise the affected real surface. Add tests only for observable contracts or plausible regressions.
7. **Expose failures.** Fail loud at boundaries, represent errors explicitly, and make every fallback visible.
8. **Apply expert judgment.** Test each material choice against the relevant expert's strongest credible objection. Choose a better option or state the tradeoff to the Operator.
