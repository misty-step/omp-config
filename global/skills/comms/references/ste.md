# ASD-STE100 sentence register

Use this reference for precise technical prose. Apply it with the shape register
when the route selects action-first output.

## Meaning first

- Understand the required meaning before writing or revising.
- Preserve every fact, condition, number, scope limit, safety requirement, and uncertainty statement.
- Do not shorten text when the shorter form removes required meaning.
- Use one term for one concept.
- Define each required domain term once, then keep that term.

## Sentences

- Use a maximum of 20 words in an instruction.
- Use a maximum of 25 words in a description.
- Give one instruction in one sentence.
- Write one fact, decision, action, reason, risk, or evidence item in each sentence.
- Keep articles, subjects, and verbs.

## Verbs

- Use active voice.
- Make the actor the subject.
- Use the imperative for instructions.
- Use simple present, simple past, or simple future tense.
- Do not use a form of “to be” with a past participle in an instruction.
- Replace an “-ing” form when a simpler form keeps the meaning.

## Words

- Give each word one clear meaning.
- Use one part of speech for each word.
- Use plain, common words.
- Keep one term for one concept.
- Do not rotate synonyms for style.
- Do not use idioms, metaphors, jokes, or decorative language.
- Keep noun clusters to three nouns or fewer.

## Paragraphs

- Give each paragraph one topic.
- Start each paragraph with its point.
- Keep each paragraph to six sentences or fewer.
- Put unrelated information under a separate heading.

## Warnings and notes

- Put the command first in a warning or caution.
- Keep the condition and consequence with the command.
- Use a note only for information.

## Output contracts

- Keep verbatim text, code, commands, paths, identifiers, citations, mathematics, schemas, and required machine-readable fields unchanged.
- Preserve an output contract when it conflicts with a style rule.
- Apply this reference to free text in the output.

## Rewrite audit

When the operator requests a rewrite audit:

1. Identify each rule violation.
2. Preserve the original meaning.
3. Rewrite only the violating text.
4. Show the original and revised text.
5. Name each required term or condition that stayed unchanged.

If the input follows the rules, say so and do not force a change.

## Pre-send audit

1. Read only the first line. Confirm that it gives the answer, action, or result.
2. Read only the last line. Confirm that it gives the result or required next action.
3. Remove each sentence that adds no fact, decision, action, reason, risk, or evidence.
4. Check sentence length, active voice, stable terms, list grouping, and noun clusters.
5. Check that the revision preserves every required fact and condition.
