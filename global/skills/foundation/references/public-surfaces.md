# Public surfaces

## Marketing site minimum

- Lives in-repo when practical (`site/` or project-native equivalent).
- States product name, pitch, what it does, and where the code lives.
- Shows at least one screenshot or GIF of real product behavior.
- Names install or get-started path.
- Deploys through a documented public path (Pages, static host, or product host).

Do not require Aesthetic tokens or house chrome.

## Docs site minimum

- Committed `docs/` and/or a published docs URL.
- Linked from README and marketing site when both exist.
- Covers install, core concepts, and operator/agent entrypoints at minimum.
- Prefer `/document` when deep reference docs are missing or stale.

## README proof

- Pitch above the fold.
- Quickstart that a cold user can run.
- Media: screenshot and/or GIF adjacent to the pitch when the product is visual
  or interactive.
- Links: docs, marketing site, license, and primary repo surfaces.
