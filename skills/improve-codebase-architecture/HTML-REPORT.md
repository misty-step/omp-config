# Architecture Report

Create one offline HTML file with inline CSS and SVG.

Show:

1. Repository, scope, date, and evidence boundary.
2. Zero to three candidates, strongest first.
3. One recommendation, or a no-change result.

Each candidate contains:

- deletion or deepening title and strength;
- affected files and callers;
- observed problem and evidence;
- before-and-after ownership or call-flow diagram when useful;
- proposed owner and interface;
- deleted concepts;
- preserved invariants;
- migration risk and proof.

Use semantic HTML, labelled edges, system fonts, visible focus, sufficient
contrast, responsive layout, and print-safe cards. Use one accent color. Remove
decoration.

Use the skill's terms consistently. Replace vague quality claims with a
mechanism and observable effect.
